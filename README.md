# 拾光 ✨

> **记账，也记日子。**
> 账单和生活记录汇成同一条时间线——某天花了多少钱、随手拍了什么、和谁见了面，翻回去就是一本带价格的手账。

## 🌱 这是什么

「拾光」是一个开源的生活记录 PWA（网页应用）：

- **3 秒记一笔账**：金额 + 分类 + 备注，支出收入一键切换
- **随手记生活**：拍张照、写句感慨、标记「和谁在一起」
- **时间线手账**：账单和动态按天汇成一条流，每天自动汇总当日支出
- **月度生活报告**：这个月花了多少钱、拍了几张照片、最常见面的人是谁
- **完全本地**：数据只存在你自己的设备里，无需注册登录，绝不上传
- **离线可用**：添加到主屏幕后，断网也能照常使用

## 📲 怎么使用

**方式一：直接打开网址（推荐）**

👉 **<https://vvy1224.github.io/shiguang/>**

用手机或电脑浏览器打开就能用。

**方式二：装成「App」（体验更好）**

1. 手机浏览器打开上面的网址
2. 浏览器菜单 →「添加到主屏幕」/「安装应用」
3. 桌面会出现拾光图标，点开即全屏运行，和原生 App 一样

> 📌 数据存在设备本地：换手机或清浏览器数据前，请先在「我的 → 导出备份」保存一份，新设备用「导入恢复」即可迁移。

## 🧺 功能一览

| 模块 | 说明 |
| --- | --- |
| 今天 | 今日支出、本月预算进度、今日记录 |
| 时间线 | 按天分组的手账流，照片九宫格、点击放大 |
| 统计 | 月度收支、分类构成、近 6 个月趋势、生活报告照片墙 |

## 🔧 自己部署一份

整个应用是纯静态网页（原生 HTML / CSS / JS，零框架零依赖）：

```bash
git clone https://github.com/vvy1224/shiguang.git
# 任意静态服务器打开即可，例如：
cd shiguang && npx serve
```

也可以直接上传到你自己的静态托管（GitHub Pages / Netlify / Vercel 等）。

## 🛠️ 技术说明

- 原生 JavaScript，无任何框架与构建步骤，源码即成品
- **IndexedDB** 本地存储（条目 / 照片 Blob / 设置）
- **PWA**：manifest + Service Worker 离线缓存
- 图片自动压缩（长边 1600px）后入库，控制空间占用
- 温暖手账风 UI，标题使用 [霞鹜文楷](https://github.com/lxgw/LxgwWenKai)（CDN 加载）
